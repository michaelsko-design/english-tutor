### Features

- [ ] **Vibe-o-meter** - A 0-100% gauge derived from `profile.activityLog` (no stored field, no sync change): it fills with recent practice and cools gently when days go quiet (Shabbat and shielded days count as active). It never removes points or levels, and its copy is encouraging, not punishing.

Also create a coupon system for discounts, promotions etc.
- [ ] **Self-issued PIN recovery code** (low priority) - A child with no parent can save a recovery code from settings and later set a new PIN with username + code (`api/recover-pin.ts`: look up the uid via `usernames/{slug}`, constant-time hash compare, rotate the code). - [ ] **Streak reminder emails via Resend** (low priority) - Optional parent/learner emails on top of the push reminders: a streak-saver email and a Sunday weekly-report email (`buildWeeklyReportTextHe`), sent through Resend from the daily cron. Needs an email field with consent (children's data, `docs/architecture.md` §4.21), `firestore.rules` and the smoke test updated, a Resend account/API key, an unsubscribe link and the same Shabbat skipping as the push reminder.

- [x] **Feature 26**: World Map (מפת עולם) - Phase 3 of the Feature 22 redesign. The list-style mission map is now an illustrated scrolling map per grade: one region per unit on a copy of the theme's map background, with the unit's banner (number, Hebrew and English titles, stars) covering the join between two copies. An SVG path follows the background's winding band (a sandy road on PeachNote, a light glowing path on the dark themes) and turns gold up to the current mission. Missions are coins: gold with 1–3 stars when done, pulsing with the companion standing on it when next, grey with a lock when locked. Each unit has its landmark beside the path (its badge emoji until the picture exists), and each Boss is a castle showing the stars earned toward its gate (e.g. 👑 3/4 ⭐) that opens with an animation, once per device, when the gate is met. Tapping a stop opens a bottom sheet with the full mission card: the whole title, story, rewards, the tier choice, words to hear and Start (or why it is locked). The map scrolls to the current mission when it opens. Unlocks, the Boss gate and rewards are unchanged.
