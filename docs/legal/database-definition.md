# מסמך הגדרות מאגר: EnglishVibe

> **מסמך פנימי** לפי תקנה 2 לתקנות הגנת הפרטיות (אבטחת מידע), התשע״ז-2017. לא מתפרסם. נכתב ב-20 בנובמבר 2026 בעקבות הביקורת המשפטית (`docs/legal/legal-audit-implementation-plan.md`, Task 6), ואינו ייעוץ משפטי. בודקים ומעדכנים אותו **פעם בשנה לפחות**, ובכל שינוי מהותי: ספק חדש, סוג מידע חדש, או אדם נוסף שמקבל גישה.

**עודכן לאחרונה:** 20 בנובמבר 2026. **הבדיקה הבאה:** עד נובמבר 2027.

## 1. בעל השליטה והסיווג
- **בעל השליטה:** מיכאל שקולניק, בעל העסק "SHK טכנולוגיות", עוסק פטור מס׳ 310720370, החיטה 323, מאור. פניות: support@englishvibe.co.il.
- **בעלי הרשאה:** בעל השליטה בלבד (קונסולות Firebase, Vercel, Make, Grow, Cloudflare, Azure ולוח הבקרה של הבעלים באפליקציה).
- **סיווג:** מאגר המנוהל בידי יחיד. בעל השליטה הוא יחיד, אין לאיש מלבדו הרשאת גישה, והמאגר לא נועד למסירת מידע לאחרים כדרך עיסוק. לכן אין חובת רישום, אין ממונה הגנת פרטיות ואין נוהלי אבטחה כתובים מעבר למסמך הזה.
- **הסיווג נבדק מחדש אם:** מישהו נוסף מקבל גישה למידע (עובד, שותף, מפתח חיצוני), אם נשמר מידע בעל רגישות מיוחדת, או אם משתנה מטרת המאגר.

## 2. תיאור הפעילות ומטרות השימוש
EnglishVibe היא אפליקציית ווב ללימוד אנגלית לתלמידים בכיתות א׳–י״ב, עם פורטל להורים ומנוי Pro בתשלום. המידע נאסף כדי:
1. להפעיל את האפליקציה: לשמור את ההתקדמות ולסנכרן אותה בין מכשירים, להתאים את התרגול לכיתה, ולפנות ללומד/ת במגדר הנכון.
2. להפעיל את מרכז החברים ואת הדוח להורים, כשהם מופעלים.
3. לגבות תשלום על Pro ולטפל בביטולים, בשינויים ובהחזרים.
4. לשפר את האפליקציה: מוני פעולות ודוחות שגיאה מקושרים לחשבון. אפשר לכבות אותם בהגדרות.

## 3. סוגי המידע
| קבוצה | מה נשמר | כמה זמן |
|---|---|---|
| לומדים (רובם קטינים) | שם פרטי, מגדר, כיתה, שם משתמש או חשבון Google, התקדמות, יומן פעילות של 12 שבועות, רשימות מילים, חלומות, ציורים, העדפת מנוחה בסוף השבוע, מועדי הסכמה (והסכמת הורה מתחת לגיל 13) | עד מחיקת החשבון |
| חברים | קוד חבר, פרופיל ציבורי מצומצם, חברויות, תחרויות, תגובות אימוג׳י | עד מחיקת החשבון או ניתוק החברות |
| הורים | חשבון Google, קישורים לילדים, תמונת מצב של הדוח | עד מחיקת חשבון ההורה או ניתוק |
| משלמים | שם, טלפון, אימייל; מצב המנוי, סכומים, מספרי אישור, מועד ההסכמה לתנאים | פרטי הקשר: נמחקים 90 יום אחרי סיום המנוי והטיפול בו (`api/pro-reconcile.ts`). רשומות התשלום: כ-7 שנים לפי חוקי המס, עם מזהה החשבון בלבד |
| בודקים מוקדמים | רשומת גישה עם כינוי, ההזמנה שנוצלה, הודעות משוב | עד מחיקת החשבון |
| טכני | מזהה מכשיר פנימי, מזהה התראות דחיפה, מוני פעולות, דוחות שגיאה, סוג מכשיר כללי, מקור ההגעה (מילה אחת מרשימה קבועה) | עד מחיקת החשבון; ספירות המשפך הן סיכום יומי שלא מקושר לאיש |

**לא נשמרים:** פרטי אמצעי תשלום (נשארים אצל Grow), קוד סודי (נשמר אצל Firebase Authentication), הקלטות קול (זיהוי הדיבור נעשה בדפדפן), תעודות זהות.

## 4. העברת מידע לאחרים ומחוץ לישראל
אין מסירה לצורכי שיווק או פרסום. המידע עובר רק לספקים שמפעילים את השירות, וחלקם מחוץ לישראל (האיחוד האירופי וארה״ב):

| ספק | מה מעבד | מיקום |
|---|---|---|
| Google Cloud / Firebase | מסד הנתונים (Firestore), הכניסה לחשבון, App Check ו-reCAPTCHA Enterprise | Firestore באירופה (`eur3`); הכניסה והגנת הבוטים גם בארה״ב |
| Vercel | אחסון האתר ופונקציות השרת (`api/`), כולל יומני השרת | אירופה וארה״ב |
| Microsoft Azure | הפקת קול לטקסט שמוקרא, בלי מזהה חשבון | גרמניה (`germanywestcentral`) |
| Cloudflare R2 | קובצי השמע הקבועים של ההקראה (בלי מידע אישי) | גלובלי |
| Make (Celonis) | מעביר את פרטי המשלם ל-Grow, ושולח לבעלים התראות **בלי** פרטי המשלם (`api/_lib/ownerAlerts.ts`) | מחוץ לישראל |
| Grow (גרואו פיימנטס בע״מ) | סליקה, הוראות קבע וקבלות. חברת סליקה מורשית שאחראית בעצמה על פרטי התשלום | ישראל |

שירותי הדחיפה של הדפדפנים (Google, Apple, Mozilla, Microsoft) וזיהוי הדיבור של הדפדפן מופעלים על ידי המכשיר של המשתמש, ולא בהסכם איתנו.

## 5. הסכמי עיבוד מידע (DPA): עותק שמור מקומית
בעל השליטה שומר עותק PDF של כל הסכם, עם תאריך ההורדה, בתיקייה מקומית (לא ב-git), ובודק פעם בשנה שלא התעדכן:
- [ ] **Google Cloud / Firebase:** Cloud Data Processing Addendum (מתקבל בקונסולה: Project settings → Privacy, או Google Cloud console → Legal). לוודא שפרטי איש הקשר לפרטיות מולאו.
- [ ] **Microsoft Azure:** Microsoft Products and Services Data Protection Addendum (חלק מההסכם של המנוי, בלי חתימה נפרדת).
- [ ] **Vercel:** Data Processing Addendum מעמוד ה-Legal של Vercel.
- [ ] **Cloudflare:** Customer DPA מעמוד ה-Legal של Cloudflare.
- [ ] **Make (Celonis):** Data Processing Agreement מעמוד ה-Legal של Make.
- [ ] **Grow:** תנאי השימוש של Grow ומדיניות הפרטיות שלה (https://grow.business/privacy-policy/). Grow פועלת כגורם אחראי עצמאי לפרטי התשלום.

## 6. סיכונים עיקריים ואיך מטפלים בהם
| סיכון | טיפול |
|---|---|
| גישה לא מורשית לחשבונות הבעלים (Google, Vercel, Make, Grow, Cloudflare, Azure) | אימות דו-שלבי בכל החשבונות, גישה רק לבעלים, ומפתחות סודיים רק במשתני הסביבה של Vercel ובקובץ `.env.local` שלא נכנס ל-git |
| לומד/ת קוראים או משנים מידע של אחר | חוקי Firestore (`firestore.rules`) נבדקים מול האמולטור (`scripts/emulator/rulesSmoke.mjs`); App Check חוסם לקוחות שאינם האפליקציה |
| מידע מזהה בטקסט שמוקלד להקראה | מודעת הפרטיות מבקשת לא להקליד פרטים מזהים; התשובות לא נשמרות במטמון ציבורי (`Cache-Control: private, no-store`). ידוע: הטקסט מופיע בכתובת ובקובצי היומן של Vercel |
| פרטי משלם נשמרים יותר מהנדרש | מחיקה אוטומטית אחרי 90 יום (`api/pro-reconcile.ts`) |
| מידע נשאר אחרי מחיקת חשבון | המחיקה מוחקת את הרשומות בשרת ובמכשיר (`api/_lib/eraseAccount.ts`, `src/utils/clearLocalData.ts`) |

**אירוע אבטחה:** בודקים מה נחשף ולמי, סוגרים את הפרצה (מחליפים מפתחות, מתקנים חוקים), ושוקלים דיווח לרשות להגנת הפרטיות ולמשתמשים שנפגעו.

## 7. גישה לתיקון ולמחיקה
עיון, תיקון ומחיקה לפי סעיפים 13 ו-14 לחוק: בהגדרות האפליקציה (הורדת המידע ומחיקת החשבון), בפורטל ההורים (מחיקת חשבון ההורה), ובאימייל support@englishvibe.co.il עם מענה בתוך 3 ימי עסקים.
